# Masterarbeit_Jonathan_Foltz
In diesem Repository befindet sich der Code zu meiner Masterarbeit mit dem Titel 'Sparsity-basierte gemischt-ganzzahlige Optimierung zum Lernen algebraischer Gleichungen aus Daten'.

Vor Ausführung des Codes müssen einige Pakete installiert werden mit dem Folgenden Befehl: 

pip install numpy pandas matplotlib pyscipopt

Die Methode run_all_experiments_from_masters_thesis() führt alle 56 Experimente, die in der Masterarbeit beschrieben sind, nacheinander aus. Mit run_specific_experiment(<Experiment_Nummer>) kann ein spezifisches Experiment ausgeführt werden.
